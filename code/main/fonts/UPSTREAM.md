# OLED text font

`font8x8_basic.h` comes from https://github.com/dhepper/font8x8 at commit
`8e279d2d864e79128e96188a6b9526cfa3fbfef9`.

The upstream header declares this font public domain and credits Daniel Hepper,
Marcel Sondaar, and the IBM VGA fonts. Those notices are retained. The only
change is declaring the array `static const unsigned char` for embedded use.
