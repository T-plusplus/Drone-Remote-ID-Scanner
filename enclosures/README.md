# Enclosures

- `cad/`: reserved for future editable enclosure models (e.g. FreeCAD, STEP, OpenSCAD).
- `prints/`: reserved for future STL/3MF files ready for slicing and printing.

No enclosure models are needed for the breadboard proof of concept. Measure the
final board, OLED breakout, button, and connectors before enclosure design.
